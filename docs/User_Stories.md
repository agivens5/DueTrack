# User Stories

## Authentication

- As a student, I want to register for an account so I can securely access my data.
- As a student, I want to log in so I can manage my courses and assignments.
- As a student, I want to log out to protect my account.

## Courses

- As a student, I want to create courses for each class I am taking.
- As a student, I want to edit course information if something changes.
- As a student, I want to delete courses I no longer need.

## Assignments

- As a student, I want to create assignments with due dates.
- As a student, I want to update assignment details.
- As a student, I want to mark assignments as complete.
- As a student, I want to search, filter, and sort assignments.
- As a student, I want to view assignments on a calendar.
