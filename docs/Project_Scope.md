# Project Scope

## Overview

The goal of this independent study was to design and develop a full-stack web application that allows students to manage courses and assignments through a secure web interface.

## Objectives

- Develop a RESTful backend using Node.js and Express.js.
- Design a relational SQLite database.
- Build a responsive frontend using HTML, CSS, and JavaScript.
- Implement secure user authentication.
- Provide full CRUD functionality for courses and assignments.
- Test the application using Jest and Supertest.

## Deliverables

- Full-stack DueTrack application
- SQLite database
- REST API
- User authentication
- Automated API tests
- Project documentation
