# Final Reflection

## Project Summary

During my COSC 495 Independent Study, I designed and developed DueTrack, a full-stack web application that helps students organize courses, assignments, due dates, priorities, and completion status.

The project began as a simple assignment tracker and gradually evolved into a complete web application with secure authentication, a RESTful backend, a relational database, automated testing, and an interactive user interface.

---

## Major Accomplishments

Throughout the project I successfully:

- Designed a relational SQLite database
- Built a RESTful API using Node.js and Express
- Implemented full CRUD functionality
- Developed a responsive frontend using HTML, CSS, and JavaScript
- Integrated the frontend with the backend
- Added secure user authentication using bcrypt and express-session
- Protected application routes using authentication middleware
- Implemented automated API testing using Jest and Supertest
- Created project documentation throughout the development process
- Used Git and GitHub for version control and project management

---

## Skills Developed

This project strengthened my knowledge of:

- Full-stack web development
- REST API design
- Express.js
- SQLite
- Authentication and session management
- Database relationships
- Automated software testing
- Debugging complex issues
- Software documentation
- Git and GitHub workflows

---

## Challenges

One of the biggest challenges during this project was integrating user authentication into an existing application while ensuring previously implemented features continued functioning correctly.

Another challenge involved debugging Git version control conflicts while synchronizing local and remote repositories.

Working through these issues improved my debugging skills and increased my confidence using Git.

---

## Lessons Learned

This independent study reinforced the importance of planning software before implementation, testing continuously throughout development, documenting progress, and making incremental improvements over time.

I also gained a much stronger understanding of how frontend and backend components communicate within a full-stack application.
